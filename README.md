# Hamis Mlazie | ICT & Systems Administration Portfolio

Personal portfolio site built with plain HTML and CSS. No build step.

## Contents
- `index.html`: main portfolio page (skills, experience, projects, training, contact)
- `style.css`: styling
- `ticketing-system/`: help desk ticketing demo (HTML, CSS, JavaScript, localStorage)

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a public repository named `yourusername.github.io`.
2. Upload all files in this folder.
3. Go to Settings, then Pages, and choose Deploy from a branch: `main`, `/ (root)`.
4. The site goes live at `https://yourusername.github.io`.
